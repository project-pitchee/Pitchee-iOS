# Pitchee 嗓音知识库：指标定义、推荐边界与共振峰评估设计

修订日期：2026-10-05。本文说明当前 iOS 工作区中的知识库集成及后续共振峰评估的设计边界。现有 49 篇文章解释产品结果并提供学习入口，不构成临床诊断规则。

## 1. 当前指标契约

| 名称 | 当前含义与实现 | 不能推导的结论 |
|---|---|---|
| F0 / 基频 | 周期性发声的基频估计，以 Hz 表示 | 不能单独确定性别听感、健康或舒适音区 |
| 音色分（VFP） | 女性向参考的模型输出，原始字段保留 `vfp_standard_score`；有效窗口输出汇总为 0–100 | 不是共振峰、声道长度、肌肉状态或临床测量；不是经校准的听者识别概率 |
| 自然分 | 模型对日常说话的自然听感及刻意、风格化程度的估计 | 不是机器人检测或病理指标，不能判断真实意图、声门闭合程度或声带损伤 |
| 目标方向综合分 | Core 根据所选方向和产品参数计算 | 没有逐项测量情感、语调和语境等全部因素；分数高不保证他人感知或本人满意 |
| F1–F4 / 拟议共鸣分 | 独立的持续元音分析设计，当前未实现 | 不能由 VFP 换名获得；没有通用已验证的四峰加权公式 |

这些是不同维度或计算结果，但不能声称统计上相互独立。高 F0、高音色分、低自然分可以同时出现，例如模型给一段较高音、明显角色化的表达作出这一组合；该例说明维度有别，不保证模型对这种声音一定如此评分。

普通 speech 的女性化听感还涉及韵律、情感表达、语言和听者情境。用户可以用现有分析观察综合分和单项反馈，但不能把它当成全部交流维度的完整测量。“自然”本身也需明确听评任务和适用表达场景，风格化声音可以是用户主动选择的目标。

## 2. 评分规则与文档边界

当前公式及分支详见 [连续评分文章](Voice-Training-Library/Module-01-Engine-Rules/RULE-CONTINUOUS-01-连续评分逻辑与各指标协同进展.md) 和 [Core scoring.cpp](../Dependencies/PitcheeCore/src/scoring.cpp)。女性向包含加权式、封顶与条件加分；男性向使用另一连续公式，自然分目前不参与，缺失 F0 时音高偏差项为零。

165 Hz、30 分、59 分等数字只属于实现参数。命中 cap 规则不一定实际降低结果；命中 `pass_boost` 也不一定高于基础分。分数区间是内容检索线索，不能命名为神经学习阶段、嗓音损伤等级或社交通过率。

原始模型字段和规则键为兼容性保留；用户文章统一使用“音色分（VFP）”与“自然分”。`METRIC-VFP-*` 等历史 ID 也不代表现在测量了共振峰或诊断了鼻音、薄声。

## 3. 推荐必须允许模型不适用

推荐先考虑采集质量、缺失数据和用户方向，再提供少量可选学习入口。质量阈值的实际含义见 [引导练习说明](Guided-Practice.md)：VAD 语音与非语音电平差只是背景干扰代理量，dBFS 不等于声压级，削波比例不是嗓音健康指标。

质量通过只能减少一部分采集疑虑，不能验证模型。音色分和自然分可能在清晰录音中系统性误判，重复得到同样结果也不能证明正确。当前没有可靠的个体误判检测器，不应把一次或多次分数异常自动翻译为“声道太大”“声带太厚”“肌肉挤压”。

| 观察 | 推荐入口的合理用途 | 必须避免 |
|---|---|---|
| 音色分与目标听感不符 | 先核对采集、表达任务和听感，可跳过相关练习 | 自动要求提亮、抬喉、缩咽或追高分 |
| 自然分较低 | 比较是否符合所需日常或角色化表达 | 推断机器音、代偿、损伤或真实意图 |
| F0 较高或较低 | 阅读测量含义，根据目标和舒适度决定是否探索 | 用统一音区判断所有人都需调整 |
| A/B 分数下降 | 检查条件与具体变化，允许无法判断 | 宣称下降证明退步或证明动作重塑 |
| 非二元或方向未定 | 按个人喜好探索，尊重两者不等同 | 默认要求女性化、男性化或中间频段 |
| 疼痛、新增或持续嘶哑等 | 按症状阅读健康与专业评估资料 | 由高分放行、由低分诊断 |

用户确认某个建议与目标无关时，可以不练。全文和推荐摘要都应先保留这条选择，再介绍可尝试的方法。模型改进或误判反馈机制需独立设计和验证，文章修订不能替代它们。

## 4. 拟议的持续元音 F1–F4 评估

这是一项待开发、待验证的独立功能设计。当前 iOS 与所检查的 Core 工作区没有元音选择、可靠 F1–F4 输出及共鸣分实现，文章不能写成现有按钮的操作教程。

候选流程如下：

1. 用户选择 `/i/`、`/u/`、`/æ/` 或 `/a/`，界面提供与参考语料一致的示例。用户已确认第一个音为 `/i/`，不是 `/ɪ/`；`/ae/` 规范写成 `/æ/`。研究中的 `/ɑ/` 不应自动当作 `/a/` 的同一参考。
2. 在舒适、较稳定的持续元音中估计 F0 与 F1–F4，保留窗口、采样与分析设置，并检查有效片段、噪声及估计稳定性。用户点选元音不等于软件已经验证实际发音。
3. 按同一元音和可比条件展示共振峰及其不确定性，避免把口型变化或发错元音误写为朝目标进步。高 F0 下谐波间距较大，可能使共振峰估计更困难；缺峰、错峰和伪峰必须允许返回无法可靠估计。
4. 如果未来要生成“共鸣分”，先定义它评估的是相对参考分布的位置、特定听评目标还是其他量；建立匹配语言、元音、录制条件的参考数据和独立验证集，检验重测、设备差异及各类声线的误差。
5. 仅在估计和评分验证满足预先设定的要求后，输出带适用范围的独立共鸣分。验证前可以探索原始共振峰，不提供看似精确的任意百分制总分。

F1 通常与元音开口度、舌高有关，F2 与前后舌位和圆唇等有关；F3、F4 还受更复杂的声道形状影响。这些是声学关联，不是可逐一操作的肌肉旋钮。不能把四个数简单平均，也不能让所有峰越高就越好；不同元音本就有不同的共振峰结构。

现有相关研究考察的是特定元音和实验条件下的感知变化。例如 [Gallena 等的研究](https://pubmed.ncbi.nlm.nih.gov/28844651/)操控 F0 和 F1–F3，不能作为通用 F1–F4 评分的验证；[Gelfer 与 Mikos 的孤立元音研究](https://pubmed.ncbi.nlm.nih.gov/16301101/)也显示 F0 会影响判断。孤立元音并没有消除所有其他感知因素，四个峰不能保证“绝不露馅”或所有场景下的女性化听感。
