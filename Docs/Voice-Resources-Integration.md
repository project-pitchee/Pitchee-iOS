## 2. 研究与内容筛选

### TWVQ-SC 的实际用途

论文公开摘要报告 260 位跨性别女性与 128 位顺性别女性参与，内部一致性 Cronbach α 为 0.969、重测 ICC 为 0.841。这些结果支持该研究条件下问卷的可靠性等测量属性，并不证明某套练习有效，也不能直接证明 App 评分有效。全文方法与完整局限尚未审阅。

它适合作为未来「声音对日常生活与自我感受的影响」评估工具的候选。正式引入前，核对原量表和中文版本权利人、准确题目/计分版本、电子化及商业使用条件，并评估对目标用户的适用性。不能删改题目后沿用已验证量表的名义，也不能直接推广到男性向、非二元或所有年龄人群。

第一版继续用已有的「更接近目标／差不多／无法判断」做主观回听记录，明确这是 Pitchee 的体验反馈，不是 TWVQ-SC，也不是临床量表。

### 编辑取舍

- 用音高、共鸣、音质、语调、日常交流和主观舒适度组织知识；一个来源可支持多个主题，但不代表支持某个具体练习或生产评分。
- 优先说明用户希望怎样表达自己。女性向教程保留其适用人群，提供其他目标用户的返回入口，不自动当成所有用户的默认课程。
- 部分社区材料给出固定的 “pass” 音高区间、训练周数、不会伤嗓或类似医院训练效果等断言。不要将这些断言变成 App 的统一目标、完成条件或效果承诺。
- 声音有疼痛、明显疲劳或不适时停止练习；持续或反复出现时建议寻求有嗓音经验的专业人员评估。技术动作、持续时长、共鸣和音色训练在发布前需要专业审校。
- 当前练习主要指标是平均音高、音高标准差和有效说话时长。它们不能单独说明共鸣、声带健康、性别认同或“成功程度”；也不要将音高标准差越低直接解释成更好。
- 原创课文和示范音频独立制作。对某一来源逐句改写、翻译或保留独特教材结构，仍可能是改编，不能只换词后标成原创。

## 3. 首版体验

建议在录音页增加「学习与练习」入口，设置页增加「资源与版权」入口，两处访问同一份资源目录。先使用现有导航结构，不需要为十个网址新增一个主 Tab。

```text
录音页 → 学习与练习
           ├─ 认识自己的声音：简短知识说明
           ├─ 开始一次练习：目标 → 原创短句 → A/B → 回听感受
           ├─ 按主题查找：音高／共鸣与音质／语调与交流／专业支持
           └─ 延伸阅读：资源详情 → 在浏览器打开原文

设置页 → 资源与版权 → 同一资源目录与许可详情
```

资源卡片显示标题、作者或机构、语言、内容类型和一至两句原创导读。类型采用「专业指南」「社区经验」「研究」「外部工具」等描述，不用笼统的“科学认证”标签。资料的许可明确程度与医学证据强弱是两件不同的事。

资源详情显示：为何推荐、适用阶段、原文语言、署名与来源、内容使用方式、许可链接（如有）、资料更新日期（如有）、核查日期，以及「在浏览器打开原文」。单独标注站点含付费服务、资料仅适用于特定地区或只核查到摘要等实际限制。

第一批原创微课可以这样安排：

| 微课 | App 内做什么 | 延伸阅读 | 版本安排 |
| --- | --- | --- | --- |
| 认识声音的几个维度 | 解释音高与听感的区别，让用户选择本次关注点 | ASHA、VCP、TransNavi | 首版；用原创说明 |
| 舒适地开始和结束 | 关注当前感受，提供暂停与专业支持入口 | VCP、UCSF | 首版；不承诺自动诊断发声健康 |
| 用同一句观察两次声音 | 复用固定短句 A/B、原有指标和回听流程 | VCP 的记录进展主题、TruVox | 首版；原创短句 |
| 从朗读走向日常交流 | 原创日常短语、情境表达、自发言语 | Sheffield、RLE/CNTT | 后续版本；先完成内容审校和新练习分组 |
| 探索共鸣与音质 | 经过审校的说明、自有音频、听感比较 | Sheffield、VCP | 后续版本；不伪造当前尚未验证的专项评分 |

外部资源在用户点击后交给系统浏览器打开。第一版不预载网页、不嵌入视频播放器、不缓存第三方全文；既便于保留原站语境，也避开 ASHA 已明示的套壳展示限制。跳转链接不携带声音目标、录音 ID、问卷答案或音频；第三方网站的麦克风与账户使用由用户在原站自行决定。资源元数据和 Pitchee 自有导读可离线展示。

## 5. 署名与许可管理

外链和原创导读示例：

> 声音目标与自主练习  
> 延伸阅读：Vocal Congruence Project — Nora Mahon、Leah B. Helou。  
> 本页导读由 Pitchee 编写。查看原文及其适用说明：[vocalcongruence.org](https://vocalcongruence.org/)。  
> 引用或收录链接不表示原作者为 Pitchee 背书。

未来经审校的 CC BY-SA 改编示例（这是署名模板，不代表本次已翻译）：

> 依据 TransNavi contributors 的《Practice for changing your voice (an introduction to voice training)》翻译并改编。  
> [原文](https://transnavi.jp/en/voice/) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)  
> 原文更新：2026-09-16；译文版本：〔实际日期与版本〕；翻译与编辑：〔实际贡献者〕。  
> 改动：〔实际的翻译、删节、结构调整与新增内容〕。本改编文本采用 CC BY-SA 4.0。  
> 保留原文所要求的其他贡献者与上游来源署名；链接到可获取的改编文本及许可说明。

不要只在设置页写“版权归原作者所有”，也不要为未查明的作者或年份编造版权行。CC 内容保留已有的版权、许可、变更及适用免责声明。图片、视频、配音、字幕与量表有单独权利时分别说明。

CC BY-SA 改编内容的相同方式共享义务，需要落实到具体改编作品；独立的软件代码不会仅因目录中有 CC 内容就自动全部变为 CC。建议内容单独存放并可取得其适用许可版本，同时核对 App 商店分发、技术限制与 CC 的禁止附加限制条款，不能假定仅加一个链接就解决所有许可问题。

RLE 的 CC BY-NC-SA 内容不应被整体改标为项目的软件许可证，也不与可商业使用的改编教材混成一个无法区分来源和条件的文件。旧版 CC 许可与新版自定义协议按具体版本分别记录。

每项内容的登记信息至少包括：

| 信息 | 用途 |
| --- | --- |
| 稳定 ID、原始标题、作者/机构、原始 URL | 确定具体作品与正确署名 |
| 语言、适用人群、主题、内容类型 | 决定展示与筛选方式 |
| 来源版本/更新日期、核查日期、核查范围 | 区分当前材料、旧材料、仅摘要和未打开的附件 |
| 使用方式 | 外链、原创介绍、引用、翻译、改编、原样转载分别登记 |
| 权利状态、许可名称/URL、许可适用范围 | 未核明、受限、开放许可、单独授权分别登记；代码许可与教材许可分开 |
| 授权证明、署名文本、修改说明、上下游来源 | 支持发布前逐项核对；私有授权信件不进入 App 包 |
| 内置版本、审校人/日期、启用状态 | 便于更新、纠错、撤下和历史追溯 |

目录默认不允许把“已公开可读”自动转换为“可内置”。外链、正文复用和素材复用的决定分别保存。新增版权不明内容保持外链或编辑候选状态。
