# 本地评分对照实验

2026-09-30。iOS 本地原型，属于隐私改进计划的 P1：验证结构化反馈、同一录音上的候选评分计算与有界汇总能否形成闭环。当前没有服务器、上传、差分隐私、安全聚合、模型下载或训练。这个原型不代表已完成正式效果研究。

## 研究问题与固定比较

问题：现有综合评分和应用封顶、提升规则之前的连续基础分，哪一种更接近用户对当次练习目标符合度的自评？

| 项目 | 本轮固定定义 |
| --- | --- |
| 基线 ID | `direction-score-v1`；当前练习方向的最终综合分 |
| 候选 ID | `continuous-base-v1`；相同方向、封顶和提升之前的基础分 |
| 标签 | 看本次分数之前，回想刚才声音，对目标符合度给出五级自评 |
| 方向 | 女性向、男性向分别汇总；未确定目标不邀请，不代为推断 |
| 分值映射 | 将 0–100 分映射到最近的 0、25、50、75、100，再编码为 0–4；中点向上取整 |
| 比较量 | 候选与自评的等级绝对差，减去基线与自评的等级绝对差；范围 -4 至 4 |
| 保存形式 | 九格差值直方图，以及邀请、反馈和分析结果类别的固定计数 |
| 主产品结果 | 继续展示并保存既有评分结果；反馈不参与生产评分，不训练模型 |

例如：自评为第 3 级，基线映射为第 1 级，候选映射为第 3 级，差值是 `0 - 2 = -2`。负值表示候选更接近这次自评；0 表示距离相同，也可能是两版产生了相同等级。

女性向使用 Core 结果中的 `composite.finalScore` 与 `baseScore`；男性向使用现有 `VoiceDirectionScore` 的镜像规则结果。候选复用同一次 Core 推理，无需再运行声学模型，也不重新读取历史录音。F0 必须为有限正数，VFP、自然度及两版分数必须有效且在范围内，否则记为不可比较；这些检查不能保证声学估计准确。

## 用户流程

1. 在“关于 → 本地评分对照”独立开启，默认关闭。基础诊断开关与本实验互不联动。
2. 开始录音时，将参与授权与当时的练习方向固定在内存中。中途开启不把此前开始的录音加入实验；中途关闭、清空或周期变化会使旧授权失效。
3. 录音成功结束后、最终分析之前进行随机筛选。符合条件且额度允许时，邀请概率为四分之一；每 7 天两个方向合计最多 100 次筛选、5 次邀请。
4. 被邀请时先显示一个自评问题，可选五个等级、“无法判断”或“跳过”。这时尚未运行本次最终分析，也未把本次结果写入历史；分析页不显示分数和导出入口。
5. 回答或跳过后继续正常分析，内存中计算一次差值并累加计数，随后丢弃具体自评与本次关联。重复点击、页面退出回调和迟到结果不会重复记入。

这里的随机筛选范围仅为开启后的、成功结束录音且具有明确目标的会话。录音权限和录制失败不属于这张表的分母；最终推理失败则保留在邀请后的结果计数中。达到上限即停止筛选，不能将这些数据解释为全部用户、所有会话的无偏随机样本。

用户在录音期间仍可看到原有实时音高，也可能记得以前的评分；因此自评只是避免本次最终分数直接诱导的弱标签，不是严格盲评。本轮没有增加回听或收集自由文本。

## 音频与反馈的生命周期

等待自评期间，临时 WAV 会继续留在设备上，参与说明明确告知这一变化。前台通常等待 30 秒后继续分析；超时后到达的等级选择按超时处理，不进入差值统计。离开反馈页、进入非活跃状态、关闭实验或存储故障会请求跳过，继续正常分析。

系统可能暂停应用，主线程调度也可能延迟，不能承诺严格的墙钟时间上限或后台按时删除。分析退出时实验释放本次关联；未交给主产品练习回听的 WAV 在退出路径尝试删除，包含失败和取消。当前工作区同期新增了 A/B 练习回听，成功的 take 可能继续由练习会话持有，结束练习时删除，重录替换 B 时删除旧 B；这属于主产品的本地会话功能，不是实验音频库。进程中断遗留的 `pitchee-<UUID>.wav` 在下次启动时清理。会话保留期、退出路径和删除失败仍需设备验证，不将其称为按时删除或可靠的物理擦除。

具体自评仅在内存中等待同次分析；进程重启后不会恢复或推测等级。未回答就中断，分别增加反馈中断和分析中断计数；回答后中断，只增加分析中断，不伪造配对损失。设置页保留这些分母，避免只统计成功且愿意回答的人。

## 落盘数据白名单

文件位于 App 沙盒 `Library/Application Support/LocalScoreStudy/state.json`，最多 16 KiB，原子写入，iOS 完整文件保护，目录排除系统备份。

| 字段 | 目的与边界 |
| --- | --- |
| `schemaVersion`、`baselineID`、`candidateID` | 固定本地结构与比较规则；不接受远程脚本或自定义候选 |
| `configuration` | App 版本、构建号、模型清单 SHA-256、测量定义版本 |
| `enabled`、`periodStartedAt` | 独立参与设置和本地周期边界；没有逐条录音时间 |
| `usedScreens`、`usedInvitations` | 跨方向的已消耗额度；清空后仍保留 |
| `summaries[2].screened / invited` | 两个方向各自的筛选与邀请次数 |
| `summaries[2].responses[5]` | 已评级、无法判断、跳过、超时、运行中断次数；不保存具体等级分布 |
| `summaries[2].analyses[4]` | 双版分数有效、不可用、失败或取消、运行中断次数 |
| `summaries[2].lossDifferences[9]` | -4 至 4 的差值直方图；只在有效评级与有效分数同时存在时累加 |

`analyses.comparable` 是具有两版有效分数的次数；`paired` 是九格直方图之和，要求还存在有效自评。跳过或超时后分析成功会增加前者，不增加后者。界面“可比较次数”指后者。各类缺失不能按中间等级或零误差处理。

实验文件没有音频、文件路径、UUID、转写、embedding、曲线、精确分数、个人标签或逐次记录。临时授权和关联令牌不序列化。产品原有历史仍会保存完整分析结果；当前练习功能也有独立的 A/B 对比反馈字段，不属于本实验的五级自评。本实验不创建“五级自评—录音—评分”的逐次关联表，不读取练习对比反馈，也不会把历史变成上传队列。

**本地汇总依然是敏感数据。** 小样本计数及其增量可能暴露一次回答的信息，特别是结合本机历史时；固定字段、分桶和不存逐条记录不等于匿名化。这些计数未加噪，不能直接上传，不能承诺在设备被控制后仍防止推断。

## 清空、保留与异常

- 一个周期为 7 天。下次启动、进入前台、执行实验操作或打开设置页时检查过期；设置页显示期间每分钟检查。应用不运行时不保证准点删除。
- 关闭和清空会删除汇总、丢弃内存标签并使旧令牌失效，保留周期起点与已用额度。重新开启不能在正常流程中重置额度。
- App、模型清单或测量定义变化会清空汇总并保留本周期额度；候选 ID 或结构不兼容时停止实验，不静默接续不同研究。未来更新规则必须更新 ID 和相应参与说明。
- 时钟回退会清空汇总并使在途授权失效，保留原周期边界与额度。这不是抵御卸载重装或恶意改时钟的可信贡献限制，也不是差分隐私预算账本。
- 启动校验文件大小、结构、固定数组长度、计数范围与关系；异常时默认停止实验。存储错误不降级为无提示的内存采集，正常分析继续运行。
- 删除或写入失败时显示“部分资料可能尚未清除”；未成功持久化的关闭/清空不能承诺跨重启生效。应用进程之外的旧备份也不能追溯删除。

## 结论的适用范围

这轮候选用于验证流程，并没有事先证明取消封顶或提升就更合理。五级自评与分数分桶的映射包含等距假设，尚未校准；主观目标符合度、外部听众感知和声学准确性也不是同一指标。每设备最多五次邀请不足以进行效果判定，界面只展示次数，不发布显著性、胜者、性别身份或发声健康结论。

正式研究需另行固定：独立验证目标、标签定义与一致性、候选参数和版本、安装级抽样与隐私会计、样本量与统计功效、缺失处理、不同方向的分析和多重比较策略、失败率与性能门槛。当前候选只改变规则，无需新增推理；后续更换声学模型时才加入额外计算、发热、电量、超时的资源约束与独立分母。

在安全聚合与差分隐私基础设施完成之前，研发不能从这个模块获得真实用户的群体数据。可先用合成输入和经授权的本地研究检验假设；正式发布模型还需冻结验证集、独立听评与回滚条件。
