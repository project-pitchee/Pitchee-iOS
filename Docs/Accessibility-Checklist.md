# Pitchee Apple 平台无障碍清单

检查日期：2026-09-30。范围为当前 SwiftUI iOS App，包括引导、录音、练习回放、洞察、结果、设置和导出。Android 与原生分析算法不在本次改造范围内。

本清单区分「应用侧已实现」和「辅助技术实际验收」。编译成功、截图正常或标签存在，都不能单独证明可在 Screen Curtain、Voice Control、Switch Control 或 Assistive Access 下完整使用；在完成下面的实机流程前，不应据此在 App Store Connect 宣称全部支持。

## P0：核心流程

| 能力 | 应用侧实现 | 验收重点 |
| --- | --- | --- |
| VoiceOver | 原生按钮、选择器、表单和导航；录音与播放控件有名称、状态、提示；分析开始、完成和错误会通知；结果标题可聚焦 | 从首次启动到录音、结果、回放、字幕、导出，全程开启 Screen Curtain；检查每个可见文本和操作的顺序 |
| 大字号 | 引导、洞察、琴键改用语义字号；统计卡片和复合行在辅助功能字号下纵向排版；底部录音栏允许换行；日期选择提供列表；声音比例图提供文字布局 | 在最大辅助功能字号、窄屏、横屏和较长翻译下，文字不截断，主要操作可到达 |
| Reduce Motion | 引导、琴键缩放、数字与图标切换、导出页动画遵循设置；实时移动曲线替换为数值显示，仍可打开最近数据 | 录音期间不出现持续平移的曲线；打开最近数据、切换结果和翻页时无额外运动 |
| 不只依赖颜色 | 偏好有选中符号；播放有扬声器符号；趋势有方向箭头；日期有形状和文字状态；导出三类曲线使用实线、虚线、点线及对应图例 | 灰度、色彩滤镜和不同颜色辨识条件下仍可区分状态和系列 |
| 对比度与深色界面 | 界面使用系统前景/背景；关键统计数值使用主文本颜色；低透明度说明改为语义辅助文字；高对比度下曲线和自绘边框增强 | 用 Accessibility Inspector 测量实际颜色，包括未选中、禁用、选中、浅色、深色和玻璃背景 |
| Voice Control | 保留原生按钮语义；录音、琴键、声音详情、回放设置与可见文案匹配的输入名称；有明确翻页、关闭、取消操作 | 用可见文字或「显示名称」完成流程；同名回放按钮可通过第一遍/第二遍区分 |
| 自定义控件和图表 | 音高 Canvas 提供带时间轴、对数音高轴和间隔的 `AXChartDescriptor`；静态数据快照保留无音高区间；洞察图可通过原生选择器选择日期 | 音频图不把静音当作 0 Hz，也不跨间隔连接；数据快照在阅读期间保持稳定 |
| 手势替代与触控目标 | 琴键有普通激活、持续播放和停止动作；支持空格/回车；报表有翻页按钮；日历宽度不足以保留 44pt 单元时切换列表 | 无长按、拖拽、多点触控也可执行操作；小屏和折叠布局下保持可点击范围 |

## P1：感官和输入设置

| 能力 | 应用侧实现或适用范围 | 验收重点 |
| --- | --- | --- |
| Switch Control | 原生控件、图表数据列表、日期选择器与琴键的自定义无障碍操作提供扫描入口 | 自动扫描和手动扫描分别走通核心流程；检查选中区域与焦点回返 |
| Bold Text | 主要文字使用系统语义字体，容器允许纵向增长 | 与最大字号同时开启，检查数字、偏好说明和底部操作栏 |
| Increase Contrast | Canvas 网格/曲线加粗；自绘玻璃组件提供清晰实色边框 | 检查图线、卡片边界与状态符号，不只检查正文 |
| Reduce Transparency | 引导页底栏、录音栏、琴键、声音比例/范围组件及图片导出底栏提供不透明系统背景 | 开启后没有依赖背后内容才能识别的控件；深色模式也要检查 |
| 字幕 | 练习回放提供用户主动生成的自动字幕；只允许本机识别，设备/语言不支持时报告不可用；支持取消，离开练习清除字幕 | 在支持本机识别的真机上检查授权、拒绝、取消、成功、无语音、模型不可用和离开页面；核对实际转写，不把参考语料当作字幕 |
| 音频描述 | 当前没有内置教学视频或包含关键视觉叙事的媒体；声音比例、音高和统计图通过语义数据表达 | 将来加入视频时，重新评估音频描述与字幕，不能沿用本次「无对应媒体」结论 |
| Mono Audio | 琴键合成输出为单声道；练习录音的关键反馈同时提供文本/数值，不通过左右声道传递不同含义 | 真机单声道及左右平衡端点下检查琴键、录音回放；数据仍能理解 |
| Invert Colors / Color Filters / Grayscale | 语义系统颜色、文字、形状及线型共同表达信息 | 反转与灰度实测；报告图片保留固定纸张颜色，同时提供等价文本报告 |
| Button Shapes | 自绘琴键和洞察卡片遵循按钮形状/边框需求，其余使用原生按钮及明确边界 | 开启按钮形状后检查纯图标控件、导航入口和选择卡片 |
| Dim Flashing Lights | 没有频闪、闪光视频或闪烁奖励效果；播放状态使用静态符号 | 录音、回放、连续操作和错误场景下确认没有高频闪烁 |
| 数据导出 | PDF/PNG 是视觉纸张布局；新增可选择、可读屏、可保存的 UTF-8 文本报告，包含所选指标及曲线采样数据 | 用读屏阅读文本导出，核对选择集合、数值、单位、缺失值和完整时间范围；不宣称视觉 PDF 已被语义标记 |

字幕会识别用户实际录音，结果可能不准确，因此保留自动字幕提示。代码强制 `requiresOnDeviceRecognition = true`，不允许自动回退到服务器；字幕与音频的生命周期一致，不写入历史或日志。首次触发可能出现系统语音识别授权。当前新增文案提供简体中文和英文，其余语言使用系统本地化回退，仍需翻译审核。

## P2：进阶导航与简化体验

| 能力 | 应用侧实现 | 验收重点 |
| --- | --- | --- |
| 自定义 VoiceOver Rotor | 结果页「结果分区」转子定位评分、声音特征、建议与资源；没有显示评分时不加入该入口；标题同时支持系统标题转子 | 每个入口必须对应可聚焦的当前可见内容，切换目标后不留下失效入口 |
| Accessibility Actions | 琴键可通过无障碍操作持续播放或停止；普通激活仍播放短音；图表另有稳定数据列表 | VoiceOver 与 Switch Control 操作菜单均可到达；离开页面后声音停止 |
| Assistive Access | 在支持该环境值的系统上，主入口改为大文字列表，录音操作显示文字，曲线和比例图采用简化的数值/文字布局，复合行纵向排版 | 在真实 Assistive Access 会话中检查进入、返回、录音、系统授权、结果、播放与退出；旧系统保持常规布局 |
| Guided Access | 核心练习、停止录音、回放和结果阅读在 App 内完成；弹层都有明确关闭操作 | Guided Access 内走通练习；系统文件/照片导出若受会话限制，应回到 App 而不丢失结果 |
| 键盘与文本辅助 | 琴键支持焦点与空格/回车；选择器、导航、表单使用原生控件；文本报告与字幕可选择 | Full Keyboard Access 下检查焦点可见性、顺序、操作菜单和弹层关闭 |

## 可复现检查

1. 运行 `Scripts/test-pitch-image.sh`：检查完整导出图、音高快照、静音/无效值/采集间隔、图表描述更新，不依赖麦克风。
2. 使用 Xcode 构建 iOS Simulator Debug 和 iOS Release（可关闭签名）；部署目标按项目实际配置验证，不能仅凭工程全局设置推断。
3. 在 Xcode 的现有预览中选择最大辅助功能字号；结果页分别检查隐藏方向评分和显示方向评分的状态。
4. 真机开启 VoiceOver 和 Screen Curtain，从首次引导开始完成「选择偏好 → 录音 → 停止 → 结果 → 回放 → 生成字幕 → 文本报告 → 关闭」。检查提示、状态、转子与焦点。
5. 分别使用 Voice Control、Switch Control、Full Keyboard Access 重复核心流程；弹层出现后底层控件不可操作，关闭后焦点回到合理位置。
6. 将最大字号、粗体、深色、高对比度、减少透明度、减少动态效果组合开启；再检查灰度、反转、单声道。原生系统控件也要实际测试，不能仅据其类型勾选通过。

## 验证记录

- 音高图和无障碍数据：22 项自动检查通过。
- 新增无障碍/字幕本地化：检查中文、英文、非空值、译者注释与格式参数；翻译仍需人工复核。
- Xcode 27.1 / iOS Simulator Debug：完整源码快照构建通过，实际部署下限为 iOS 17.0；确认产物包含语音识别权限说明。
- 界面截图未验证：本机 iOS 27.1 运行时只提供 iPhone Duo；Device Hub 捕获返回错误，独立模拟器安装/显示查询持续无响应，所获截图为黑屏，已弃用。
- Screen Curtain、Voice Control、Switch Control、Assistive Access、字幕实际识别、对比度测量、Mono Audio 与最大字号完整交互：待真机验收。没有将这些项目记录为通过。
