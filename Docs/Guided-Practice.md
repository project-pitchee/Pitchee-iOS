# 引导练习、复测比较与可信趋势

实现日期：2026-09-30。范围为当前 iOS 工作区；保留同期尚未提交的无障碍、本地诊断和评分实验。没有修改 Core 的生产评分参数，也没有新增上传、账户或跨设备同步。

## 可用流程

1. 首页选择“开始一次练习”，或继续上次的练习类型。选择音高观察、音高稳定性、日常朗读之一，每次只突出一个指标：平均音高、音高标准差、有效说话时长。
2. 开始录音之前固定本次目标、练习类型、短句 ID、实际显示的全文和评分规则版本。同一练习的 A/B 不随系统语言或全局目标变化而改变。
3. 舒适地读完短句，停止录音。结果页先显示录音检查及保存故障，再显示主要反馈、回听和复练入口。
4. 点“用同一句再试一次”，回到固定短句，手动开始 B。仅两次均通过录音检查且主要指标有效时计算 B − A；变化正负不直接评价进步。两段音频可切换回听，同时只播放一段。
5. 可选择“更接近目标／差不多／无法判断”。这条主观反馈只保存在 B 的本地历史中，带 A 的记录 ID；不输入模型，也不接入本地评分实验的五级自评。两条历史无法成功保存时不声称反馈已保存。
6. 再次复练固定 A、删除旧 B 的音频，再录新的 B；已保存的 B 指标与听感保留于历史。要更换 A，结束本次练习并重新开始。

“继续上次练习”跨启动仅记住练习类型，创建新的 A；不会恢复已清理的音频。界面会说明这一点。当前不提供长期收藏音频。

## 质量门槛及限制

`capture-quality-v1` 使用已有 VAD、音量窗和原始样本，独立于自然度和方向评分：

| 条件 | 处理 |
| --- | --- |
| 有效说话不足 5 秒 | 提示读完全文，排除默认比较基线 |
| 语音电平中位数低于 −45 dBFS | 提示稍靠近麦克风，排除基线 |
| 实际非语音窗与语音的中位电平差小于 10 dB | 提示可能有背景干扰，排除基线 |
| 至少 1% 的输入样本绝对值不小于 0.999 | 提示可能削波，排除基线；每个原始声道分别检查，避免下混相消漏检 |
| 语音电平或削波检查缺失／无效 | 显示检查未完成，排除基线 |
| 无可用非语音窗 | 明确提示背景未知；不拿最安静的语音窗冒充背景，其他检查通过时仍可纳入 |

这些是待真机校准的录音条件启发式规则，不是信噪比测量、发声健康诊断或“声线正确性”判断。自然度较低不再生成确定的发声问题建议。完全无语音、读写或推理失败时沿用分析错误流程，不伪造一条成功记录。

固定文本是练习要求，当前没有语音识别验证用户确实朗读了该文本。两次录音仍需保持相同距离、设备和环境，软件不能仅凭质量通过保证声学估计完全准确。

## 历史与趋势

每次成功分析的历史新增可选字段：`practicePayload`、`qualityPayload`、`recordedTargetRawValue`、`scoringRulesVersion`、`capturedFinalScore`、`comparedToID`、`comparisonFeedbackRawValue`。载荷包含固定的练习类型、全文和质量规则版本；Core 原始 JSON 继续保留。

- 默认历史分数读取当次保存的方向分数；设置变化不会重写结果。详情可明确切换“当时结果／按当前目标查看”，后者有重新计算提示。导出入口明确标为“导出当时结果”，综合分使用当次快照。
- 旧记录没有保存当次目标、评分规则或质量信息，不补猜。它们仍可浏览原始指标，但不进入默认练习趋势。
- “暂不确定”不保存一个暗含女性向的综合分。默认显示音高、波动和中性指标；用户可主动选择方向评分。默认声音概况和导出也不显示方向比例。
- 趋势按练习类型、目标、短句 ID、实际全文、评分规则、模型版本及质量规则分组。只纳入质量检查通过且当前指标有效的记录。
- 每个自然日分别计算每项指标的中位数、最小至最大范围和有效次数；偶数条取中间两条平均。缺失音高不计作 0，也不会阻止同一条记录的有效其他指标单独计数。
- “每日最佳”是当前指标的最高值，只在方向综合分和自然度上提供，旁边解释尝试次数的影响。音高和音高波动不设越高／越低越好的“最佳”定义。

`core-score-profile-v1` 标识 Core 的显式 feminization/masculinization profile 及其 iOS 展示契约。将来任何生产评分规则改变都必须增加版本；模型版本也应随模型更新，防止不同测量含义混合。

## 音频生命周期

临时文件继续使用 `pitchee-<UUID>.wav`，仅在本机处理，iOS 文件使用完整保护。成功分析后由本次练习持有最多两段音频；结束、替换 B、对象销毁时尝试清理；结束或替换 B 的删除失败会显示错误并阻止新录音，允许重试。失败分析或未完成的中断录音走清理路径。应用异常退出留下的文件在下次启动、开始录音之前清理。临时目录不参与系统备份，历史目录延续原有备份排除策略。

录制期间的来电等音频中断、耳机接入／拔出、离开前台，或切换到会占用音频会话的钢琴页，会停止并清理不完整的录音，保留已完成的 A/B，不自动恢复说话片段。回听在离开结果页、切换页面、后台和音频中断时停止。系统暂停和异常退出无法保证即时清理；这不是物理安全擦除承诺。

## Android 对齐边界

已核对 Android `HistoryStore.kt`、录音结果与历史回听入口。Android 当前在历史目录长期复制保存音频，并非 iOS 的“本次两段、结束清理”；不能直接套用同一隐私文案。其历史条目尚无本次目标、练习类型和评分规则快照。

本轮不修改 Android 或共享 Core 协议。移植时需同步上述快照、质量与统计定义，增加兼容旧记录的可选字段，并单独决定已有音频收藏／回听的保留策略。两个平台的临时与长期音频语义必须分别说明。

## 评分实验下一步的判定标准

以下是研究方案要求，不是本轮得出的有效性结论，也不改变生产规则：

1. 女性向、男性向分别冻结基线和候选版本、语料、目标与设备条件，分别判断；不能用合并平均掩盖某一方向变差。
2. 主指标沿用“候选与自评的绝对等级差 − 基线与自评的绝对等级差”，负值表示更接近自评；预先确定最小有意义改善幅度、样本量和不确定性区间。当前每设备每周期最多五次邀请不能承担胜负判定。
3. 同时报告邀请、回答、无法判断、跳过、失败、质量不足及有效配对分母；缺失不当作零误差。另查音高区间、质量条件下是否存在系统性损害。
4. 自评在分数前填写；本次 A/B 的分数后听感不拿来替换这个标签。若要采用外部听评或群体数据，需另行取得研究授权并定义隐私与抽样方案，现有本地汇总不自动上传。
5. 只有两个方向都达到事先登记的改善／非劣门槛，且失败率、稳定性、资源消耗与回滚条件通过，才进入独立灰度讨论。流程跑通或连续基础分看起来更平滑，都不是修改生产评分的充分依据。

小规模练习试用先观察用户是否能独立完成一次复练、是否能解释质量提示，以及是否能用自己的话描述 A/B 差异。当前没有新增用于统计这些行为的遥测。
