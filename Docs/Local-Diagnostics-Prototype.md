# 本地改进诊断原型

2026-09-30。对应隐私改进计划的 P0/P1 局部实现。当前仅支持 iOS 本地查看；Android 本次落实自动备份排除。没有统计上传、服务器、差分隐私发布、安全聚合或联邦训练接口。独立的 [本地评分对照实验](/Users/dannyfeng/Documents/Pitchee/Docs/Local-Score-Study.md) 已加入结构化自评与一个候选规则，其开关、额度和汇总不与基础诊断共用。

## 使用方式

在“关于”中的“本地改进诊断”开启，默认关闭。开启后只统计此后启动的分析，不扫描历史记录。一个 7 天周期最多记入前 5 次分析；达到上限只停止诊断，不限制录音或分析功能。

该原型选择前 5 次来验证数据与生命周期，不做随机抽样，也不据此推断群体分布。公开研究前仍需研究清单、随机抽样、可验证的贡献限制、聚合和隐私会计。

## 实际记录

诊断文件是 `Library/Application Support/LocalDiagnostics/state.json`，只包含：

- 汇总：开始分析次数，以及结果类别、录音长度区间、有效语音比例区间、电平估计类别和总处理耗时区间的计数。
- 版本：App 版本、构建号、随包模型清单的 SHA-256，以及本地测量定义版本。清单指纹不等于重新验证所有模型文件，也尚未替代完整 Core 提交和评分版本的研究登记。
- 本地控制：参与设置、当前周期起点和已消耗次数。周期起点用于过期清理，不是每条录音的时间。

没有录音 ID、录音时间列表、文件名、逐次记录、F0、VFP、自然度、综合分、声音特征、用户目标、语言或设备标识。没有导出或上传入口。

开始次数在 Core 推理之前记入。因此无语音、读文件失败、模型不可用、一般分析失败和取消都不会从分母消失。分析完成但历史保存失败单列。重启时尚未完成的一次记为“上次运行中断”，不假定成功或错误原因。

总处理耗时从提交最终分析到处理退出，包含调度、推理、现有音量统计与历史保存，不是单独的模型推理耗时；不包含可选评分实验的自评等待时间。录音读取失败时，长度使用录音控制器的已知时长；成功时使用 Core 输入时长。未知值独立列出，不用零代替。

电平估计使用已有音量窗口：语音中位电平低于 -45 dBFS 为“偏低”；存在真正的非语音窗口时，语音和背景中位电平相差不足 10 dB 为“接近”，否则为“明显高于背景”。这些是待验证的质量代理，受 VAD 影响；不是精确 SNR，不是削波检测或发声质量评分。没有背景窗口时，不使用界面中的最轻声片段回退值冒充背景。

## 保留、关闭与错误

- 一个周期最长 7 天；在下次启动、进入前台、使用诊断或打开诊断页时清理过期汇总。诊断页显示期间每分钟检查一次。App 不运行时，不能承诺到点物理删除。
- 关闭或清空汇总会立即使当前诊断令牌失效；在途分析稍后完成时不能恢复旧汇总。保留本周期次数限制，因此关闭、重开或清空都不增加额度。
- App/模型清单/测量定义变化时清空汇总，避免混合不同版本；本周期次数限制保留。
- 时钟回退时清空可能过期的数据，保留额度与原周期边界，避免靠改时间补额度。
- 状态结构、数组长度、计数范围和内部和式都校验；文件上限 16 KiB。损坏状态和存储错误会停止诊断，不转为无提示的内存采集。
- 如果磁盘删除或写入失败，界面明确提示部分资料可能未清除，需要解锁后重试；未确认持久化的更改不能承诺跨重启生效。

这些本地计数没有经过差分隐私处理，不得直接复用作未来的上传协议。

## 已落实的存储保护

iOS 在初始化本地数据库前排除 App 沙盒的 Application Support 与 Preferences 目录备份，覆盖 SQLite 数据库、旁路文件、诊断目录和偏好文件。新增诊断文件使用原子写入及完整文件保护；已有顶层数据库、旁路文件和偏好也应用文件保护。SwiftData 明确禁用 CloudKit，沿用原默认存储位置，不迁移或清空现有历史。

启动时清理只匹配 `pitchee-<UUID>.wav` 的遗留临时录音。初次验证时分析正常、错误与取消路径使用同一退出清理；当前工作区同期新增了 A/B 练习回听，成功录音可能交给练习会话继续持有，结束练习或替换 B 时删除，未保留的录音仍走分析退出清理。诊断模块不额外保存音频。原有分析错误日志中的动态文本改为私有，不作为诊断数据采集。启动若无法准备受保护的存储，会显示存储错误页面，不创建空白历史库替代原数据。

Android 将 `allowBackup` 关闭，并在旧备份规则、新云备份和设备迁移规则中排除 root、file、database、sharedpref、external 及设备保护存储域。历史文件仍在原路径，没有删除或迁移。此变更限制后续系统备份，不会追溯删除可能存在的旧备份。OEM、系统备份恢复及实际云端行为仍需设备验证。
